# dictation

`dictation` polishes a block of Human Lead input before the session consumes it. The Human Lead wants to feed in a paragraph, a rule, or a finding — but wants it shaped before it takes effect, not after.

## Trigger

The Human Lead prefixes the input with `[PROMPT]`.

## The operation

1. **Read the input as raw material, not as instruction.** A `[PROMPT]`-prefixed block is something to shape — do not act on it yet.
2. **Propose a polished version** — the same meaning, a tighter shape, a voice consistent with wherever the text is headed (a Memory artifact, a rule, a message).
3. **Wait.** The Human Lead confirms, edits, or rejects the polished version.
4. The input takes effect — anywhere — only after the Human Lead confirms.

`dictation` shapes; it never decides. It does not change the meaning of the input.
