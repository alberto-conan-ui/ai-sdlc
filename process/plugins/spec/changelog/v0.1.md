# spec v0.1 — Initial Release

**Date:** 2026-04-06
**Requires core:** v0.3+

**Summary:** First version of the spec plugin. Designed for methodology and process design projects — the meta-project (AI-Lore managing its own evolution) is the primary instance.

**Status:** Released.

---

## What this plugin provides

### Stances

- **Editor** (default) — combines strategic thinking with direct execution. Fluid: think about what needs to change, then change it. No formal design/implementation split. Entry point: `roles/editor.md`.
- **Strategist** — skeptical evaluator. Produces competitive audits, go/no-go verdicts, positioning reviews. Doesn't design or execute. Entry point: `roles/strategist.md`.

### Workflow extension

Think -> edit -> commit -> evaluate cycle. Compressed compared to SDLC — no formal phase specs or design artifacts. The domain is prose and process structure.

Strategist sessions change the cycle's character: think becomes evaluate, edit is suspended, commit becomes deliver verdict.

### Joins

| Plugin file | Core file | Relationship |
|---|---|---|
| `roles.md` | `process/roles.md` | Substitution — concrete stances replace core archetypes |
| `workflow.md` | `process/workflow.md` | Addendum — think->edit->commit layers on core focus/modes |

## Migration Steps

**New plugin — no migration path.** Projects adopting spec for the first time:

1. Declare `plugin: spec` and `plugin_version: "0.1"` in `workspace.yaml`.
2. Set `plugin_readme` to point to `process/plugins/spec/ai_readme.md`.
