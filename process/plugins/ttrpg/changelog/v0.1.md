# TTRPG Plugin v0.1

**Date:** 2026-04-07

**Summary:** Initial release. Minimal plugin validating that AI-Lore's core doesn't force unnecessary ceremony. Single stance (Game Master), think-play-capture workflow, no AT extension, no conventions extension.

---

## What's Included

- **Game Master stance** — all-in-one: world design, session prep, NPC management, rules arbitration
- **Workflow extension** — think -> play -> capture -> evaluate cycle
- **Campaign arcs as focuses** — maps TTRPG storylines to the core focus/stack model

## What's Deliberately Absent

- No AT extension — AT is optional infrastructure, TTRPG uses it only when campaign arcs need tracked decomposition
- No conventions extension — core conventions suffice for world lore, session journals, and campaign structure
- No multiple stances — one stance handles everything, validating that the core doesn't force multi-stance ceremony
